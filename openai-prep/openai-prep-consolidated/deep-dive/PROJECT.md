# Deep Dive — Project Narrative

This is where you write up the project you'll use for the OpenAI technical deep-dive round.

## How Claude Code uses this file

When you trigger **`deep dive practice`**, Claude Code reads this file and drills you on it like an OpenAI interviewer. If this file is empty or has TODOs, it'll help you fill it in instead.

---

## Pick your project

**Criteria** (your project should hit most of these):
- You owned it end-to-end, or owned a clearly separable piece
- Real technical depth (not just "shipped a feature")
- Involved trade-offs you can articulate
- Involved cross-functional work (legal, PM, ops, another eng team)
- You can speak to what you'd do differently today

## Template — fill in below

### Project name

### Headline (60 seconds)
_If someone asks "what's a project you're proud of?", this is your answer. 3-4 sentences max. What it was, why it mattered, what you specifically did._

### 5-minute version
_The walkthrough you'd give before they start drilling. Cover: context, your role, the technical core, the hardest decision, the outcome._

### 15-minute version
_Detailed walkthrough with architecture, decisions, trade-offs, alternatives considered, what changed mid-project, who you worked with, what went wrong, how you recovered._

### Architecture
_Sketch the system. What were the major components? Data flow? Where are the boundaries?_

### Hardest technical decision
_What was it? What alternatives did you consider? Why did you pick what you picked? How would you know in hindsight if you were right?_

### Cross-functional moment
_Who outside engineering did you work with? Where did priorities clash? How did you handle it?_

### What you'd do differently
_Concrete. "I'd use X instead of Y because..." Not "I'd communicate more."_

### Numbers
_Throughput, latency, scale, team size, timeline, dollar impact — whatever's true and you can defend._

## Anti-patterns to avoid

- "We" instead of "I" — interviewers cut through this fast
- Headline metrics without backing — "improved performance 10x" → "from what to what, measured how?"
- Polished monologue — they will interrupt within 90 seconds, prepare for it
- Vague "challenges" — pick specific, technical ones with real trade-offs
