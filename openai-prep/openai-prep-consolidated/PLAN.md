## Week-by-week (rough)

### Week 1 — foundations + recruiter screen
- Recruiter screen prep (start this week, finish this week)
- Coding: LRU, LRU with TTL, token bucket, sliding window rate limiter, spreadsheet deps
- Python concepts: dunder methods, `__slots__`, basic iterators
- Deep dive: pick project, draft headline + 5-min version
- Behavioral: draft AI_POV.md and one STAR story

### Week 2 — heavy technical week
- Coding: async iterators, kv store, scheduler, 2D-to-async iterator, webhook delivery
- Python concepts: generators, async, asyncio.gather/cancellation
- System design (HelloInterview): rate limiter, payments idempotency, abuse pipeline, job scheduler, auth/session, Slack at scale, webhook delivery
- Deep dive: full 15-min narrative, first drill session
- Behavioral: STAR stories 2-4

### Week 3 — integration + mocks
- Coding: 1-2 integration problems + re-do weak ones
- Polish all 4 STAR stories + AI POV
- Mock loop session
- Day before: taper, light review only

## Today's decision

When in doubt, ask: "what's my highest-leverage hour right now?"

Right now, before the recruiter screen, that's probably:
1. Draft AI_POV.md (30 min)
2. Pick and draft your deep-dive project headline (15 min)
3. One coding problem timed (60 min)

Don't try to do everything every day. Pick 2-3 things and do them well.
